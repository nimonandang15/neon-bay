Neon Bay is an original open-world crime game built with three.js. Explore a neon-lit city on foot or by car, weave through traffic, dodge the police as your wanted level rises, and play through 3 missions — with a HUD, minimap, and save support.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
